About Maille

Maille makes animated ASCII scenes you can embed in any website. Pick a scene or use your own image or text, adjust it, then copy the embed code. It is free and open source under the MIT license.

Open MailleClaude skillView on GitHub

Script embed

Works in any HTML page, Webflow (Embed element) and Framer (Embed component, HTML mode). The Copy embed code button writes it for you with your settings inside config.

<script src="https://SITE/maille.js" defer></script>
<maille-scene preset="alpenglow" style="display:block;width:100%;aspect-ratio:16/9"></maille-scene>

The scene fills its element. It pauses when out of view and shows a still frame to visitors who prefer reduced motion.

Iframe embed

For tools that only accept a URL. The settings travel in the address.

<iframe src="https://SITE/e.html?preset=alpine-day"
        style="width:100%;aspect-ratio:16/9;border:0" loading="lazy"></iframe>

Attributes

AttributeValueEffect
preseta preset nameStart from a built-in scene.
configJSONSettings copied from Maille, merged on top of the preset.
speednumberPlayback speed, 1 is normal.
pausedpresent or absentHolds the current frame.
motionalwaysKeeps animating when the visitor prefers reduced motion.
dprnumberCaps the pixel density, e.g. 1 for a full-page background.
interactivepresent or absentLets the pointer into the scene: koi follow or flee it, bait fish scatter, a click splashes.

JavaScript

const scene = document.querySelector('maille-scene');
scene.set({ agDaylight: 1, agBirds: 9 });   // change any setting live
scene.pause(); scene.seek(12.5);             // exact frame at 12.5 s
scene.play();
scene.presence = 0.5;                        // share of cells drawn, for dissolves
scene.source = videoOrCanvas;                // image scene: draw any image, video or canvas

// Without the element
const engine = Maille.create({ scene: 'waves', width: 1920, height: 1080, cols: 160 });
engine.render(canvas.getContext('2d'), 3.2);
