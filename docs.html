MailleOpen Maille

Animated ASCII scenes for any website

Start from a scene or your own image or text, copy the embed, paste it where you build. One script, no dependencies.

Script embed

Works in any HTML page, Webflow (Embed element) and Framer (Embed component, HTML mode). The Copy embed code button writes this for you with your settings inside config. An uploaded image travels inside the config, so it embeds like any other scene.

<script src="https://SITE/maille.js" defer></script>
<maille-scene preset="alpenglow" style="display:block;width:100%;aspect-ratio:16/9"></maille-scene>

The scene fills its element. Give it a size with CSS (width plus aspect-ratio or a height). It pauses when scrolled out of view or when the tab is hidden, and shows a still frame for visitors who prefer reduced motion.

Iframe embed

For tools that only accept a URL (Notion, some page builders). The settings travel in the address.

<iframe src="https://SITE/e.html?preset=alpine-day"
        style="width:100%;aspect-ratio:16/9;border:0" loading="lazy"></iframe>

Attributes

AttributeValueEffect
presetname belowStart from a built-in scene.
configJSONSettings copied from Maille. Merged on top of the preset.
speednumberPlayback speed, 1 is normal.
pausedpresent or absentHolds the current frame.
motionalwaysKeeps animating even when the visitor prefers reduced motion.

Claude skill

The site is the quick version. The films behind Maille go further: a photo given its own motion (a head that nods, grass in the wind), several shots cut together with type, rendered frame by frame to a clean MP4. That process is packaged as a skill for Claude, so you can ask for the same kind of film in plain words.

Download maille-motion.zip

In the Claude app, upload the zip from the Skills section of your settings. In Claude Code, unzip it into ~/.claude/skills/. Then ask for something like “a 10 second vertical loop of koi with the word Calm, rendered to MP4”. Rendering needs Node, Playwright and ffmpeg on your machine.

Inside: the method (SKILL.md), a film template with crossfades and titles, a frame-exact render script, and references for every setting and for photo motion.

JavaScript

const scene = document.querySelector('maille-scene');
scene.set({ agDaylight: 1, agBirds: 9 });   // change any setting live
scene.pause(); scene.seek(12.5);             // exact frame at 12.5 s
scene.play();
scene.config;                                // full resolved settings

// Without the element
const engine = Maille.create({ scene: 'waves', width: 1920, height: 1080, cols: 160 });
engine.render(canvas.getContext('2d'), 3.2);
