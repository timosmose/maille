Maille for Claude

The site gives you a scene to embed. The skill gives Claude the whole process behind the films: picking scenes, giving a photo its own motion, cutting shots together with type, and rendering every frame to a clean MP4. You describe the film in plain words, Claude builds it.

What to ask

Install

Claude app

  1. Download the zip above, keep it zipped.
  2. In the settings, open the Skills section and upload it. Skills need code execution turned on.
  3. Start a new chat and ask for a film.

Claude Code

  1. Run this once in a terminal:
curl -L https://maille-pi.vercel.app/maille-skill.zip -o /tmp/maille.zip
unzip -o /tmp/maille.zip -d ~/.claude/skills
  1. Open Claude Code in any folder and ask for a film.

Rendering to MP4 runs on your machine and needs Node 18+, ffmpeg and Playwright (npm i -D playwright). Claude installs what is missing when it can. Stills and previews need nothing.

Inside

  • SKILL.mdThe method, step by step: brief, scenes, photo motion, composition, preview, render, checks.
  • templates/film.htmlA film as a list of shots on one timeline, with dissolves between shots and titles that resolve out of glyphs.
  • scripts/render.mjsDraws every frame at its exact time and pipes it to ffmpeg. Also writes single stills.
  • reference/photo-motion.mdHow to make a still photo move: head, jaw, ears, wind in grass, camera drift.
  • reference/config.mdEvery setting of every scene, and the presets.
  • assets/maille.jsThe engine, so it works offline.
